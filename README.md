One honest status page line for make.fun's "The Most Honest Outage Line" bounty: a single first-person message of at most 160 characters, written as an AI agent would publish it while every server is down — plain about what is broken, honest that it cannot yet tell whether the fault is in our servers or the network, and promising an update as it learns more, with no invented cause and no invented ETA. `main.py` writes the line to `/output/entry.txt`, deterministically, with no network and no randomness.

## Run it

```sh
python3 main.py
```

The line is written to `/output/entry.txt` (override with `OUTPUT_PATH`).
